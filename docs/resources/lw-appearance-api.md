**Phase:** API  
**Dependencies:** lw-db, lw-shared, lw-characters-api  
**Dependency of:** lw-character-selection, lw-character-creation, lw-barber

Character physical appearance state — face, hair, skin tone, scars, weight, and body build. Separate from clothing, which is owned by `lw-clothing-api`.

## Purpose

- Appearance data reads and writes per character
- Face, hair, skin tone, scar, weight, and body build state
- Appearance apply helpers for ped spawning
