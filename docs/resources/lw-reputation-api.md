**Phase:** API  
**Dependencies:** lw-db, lw-shared, lw-characters-api  
**Dependency of:** lw-crime, lw-gangs, lw-bounty-hunting, lw-tribal-governance

Faction, NPC, and player reputation tracking. Separate from wanted levels, which are owned by `lw-legal-api`. Reputation affects NPC behaviour, pricing, and access to certain gameplay systems.

## Purpose

- Per-faction reputation reads and writes
- NPC disposition state per character
- Player-to-player reputation tracking
- Reputation decay over time
