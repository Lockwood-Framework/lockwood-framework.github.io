**Phase:** API  
**Dependencies:** lw-db, lw-shared, lw-characters-api  
**Dependency of:** lw-horses

Horse cosmetic appearance state — coat colors, mane and tail style, and markings. Separate from horse ownership and bonding state, which is owned by `lw-horses`.

## Purpose

- Primary, secondary, and tertiary coat color state
- Mane and tail style reads and writes
- Marking and brand state
- Appearance apply helpers for horse ped spawning
