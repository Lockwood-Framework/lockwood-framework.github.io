# lw-characters-api

**Phase:** API  
**Dependencies:** lw-db, lw-shared, lw-core  
**Dependency of:** every resource that touches character data

Character identity, CRUD, slot management, tombstone tracking, and account-level name uniqueness. lw-characters-api is a data layer — it owns the character row and tombstone row and nothing else. Extension tables are owned by their respective resources and reference back via `state_id` FK.

## Design principle

This resource does not know about gameplay systems. Gameplay resources call into it — it does not call into them.

## File structure

```
lw-characters-api/
├── fxmanifest.lua
└── server/
    ├── config.lua
    ├── slots.lua       -- slot allowance, name availability
    ├── characters.lua  -- character CRUD and location save
    ├── tombstone.lua   -- tombstone and memorial reads
    └── main.lua        -- bootstrap, migrations, events, save loop
```

Server-only resource. No client scripts.

## Database

### `lw_characters`

| Column | Type | Notes |
|---|---|---|
| `state_id` | VARCHAR(17) PK | Generated by lw-core, inserted here |
| `license2` | VARCHAR(60) NOT NULL | FK → lw_players.license2, CASCADE |
| `first_name` | VARCHAR(32) NOT NULL | |
| `last_name` | VARCHAR(32) NOT NULL | |
| `status` | ENUM('active','deceased') | Default `active` |
| `last_x` | FLOAT NULL | |
| `last_y` | FLOAT NULL | |
| `last_z` | FLOAT NULL | |
| `last_heading` | FLOAT NULL | NULL until first save — consumers must handle nil |
| `deceased_at` | TIMESTAMP NULL | Set by SetCharacterDeceased |
| `created_at` | TIMESTAMP | |
| `last_played_at` | TIMESTAMP | Updated on lw-core:characterSelected |

### `lw_character_tombstones`

| Column | Type | Notes |
|---|---|---|
| `state_id` | VARCHAR(17) PK | Original state ID — persists after character deletion |
| `license2` | VARCHAR(60) NOT NULL | |
| `first_name` | VARCHAR(32) NOT NULL | |
| `last_name` | VARCHAR(32) NOT NULL | |
| `epitaph` | VARCHAR(250) NULL | NULL = no memorial entry |
| `died_at` | TIMESTAMP | |

No FK from tombstones back to `lw_characters` — the character row is deleted after 7 days, the tombstone must survive independently.

::: info Migration registration
Migrations are registered inside `AddEventHandler('lw-core:ready', ...)` because `lw_characters` has a FK to `lw_players`. This guarantees `lw_players` exists before the FK is evaluated.
:::

## Config

```lua
Config.DefaultSlots = 4    -- fallback slot allowance for all players
Config.MaxSlots     = 8    -- hard ceiling, overrides clamped to this at startup
Config.SaveInterval = 300  -- seconds between periodic location saves

Config.SlotOverrides = {
    ['license2:xxxx'] = 6,
}
```

Slot allowances are in-memory and config-driven. No DB column. Deceased characters do not count against a player's slot allowance.

## Character status

| Status | Meaning |
|---|---|
| `active` | Normal playable character |
| `deceased` | Permadeath chosen. 7-day NPC ragdoll. Row persists. Tombstone written at transition |

## Permadeath flow

1. Player downed → `lw-mortality` presents permadeath choice
2. Player chooses permadeath → prompted for epitaph (optional, 250 char max)
3. `lw-mortality` calls `SetCharacterDeceased(stateId, epitaph)`
4. Atomically: `status = 'deceased'`, `deceased_at = NOW()`, tombstone row written
5. After 7 days → `lw-mortality` calls `DeleteCharacter(stateId)` → hard delete, CASCADE cleans extension tables, tombstone persists

## Pruning flow

Players over their slot allowance on connect are blocked from selecting a character until they hard-delete enough characters to come within allowance. No tombstone is written for pruned characters — names become reusable.

## Name uniqueness

Per-account only. `IsNameAvailable` checks both `lw_characters` and `lw_character_tombstones` for the given `license2`. Comparison is case-insensitive.

## Server exports

### Reads

```lua
exports['lw-characters-api']:GetCharacter(stateId)
-- Returns full lw_characters row or nil

exports['lw-characters-api']:GetActiveCharacter(source)
-- Reads stateId from lw-core session, returns character row or nil

exports['lw-characters-api']:GetCharactersByLicense2(license2)
-- Returns all Active + Deceased rows for account, ordered by last_played_at DESC

exports['lw-characters-api']:GetSlotInfo(license2)
-- Returns { allowed, used, characters[] }
-- used = Active count only. characters[] includes Active and Deceased.

exports['lw-characters-api']:IsNameAvailable(license2, firstName, lastName)
-- Case-insensitive. Returns boolean.

exports['lw-characters-api']:GetDeceasedCharacters()
-- Returns all rows where status = 'deceased', including last coords
-- Used by lw-mortality on restart to rebuild corpse NPCs

exports['lw-characters-api']:GetTombstone(stateId)
-- Returns tombstone row or nil

exports['lw-characters-api']:GetTombstonesByLicense2(license2)
-- Returns all tombstone rows for account, ordered by died_at DESC

exports['lw-characters-api']:GetMemorialEntries()
-- Returns all tombstone rows where epitaph IS NOT NULL, ordered by died_at DESC
```

### Writes

```lua
exports['lw-characters-api']:CreateCharacter(license2, data)
-- data: { stateId, firstName, lastName }
-- stateId must be pre-generated by lw-core:RequestStateId
-- Validates name availability before insert
-- Returns boolean, string|nil (success, error message)

exports['lw-characters-api']:UpdateCharacter(stateId, data)
-- Partial update. Whitelisted fields: first_name, last_name
-- Returns boolean

exports['lw-characters-api']:SaveLocation(stateId, coords, heading)
-- coords is vector3, stored as separate float columns

exports['lw-characters-api']:SetCharacterStatus(stateId, status)
-- Generic setter. Use SetCharacterDeceased for permadeath.
-- Returns boolean

exports['lw-characters-api']:SetCharacterDeceased(stateId, epitaph)
-- Atomically sets status, deceased_at, and writes tombstone
-- epitaph is nullable. 250 char cap enforced.
-- Returns boolean, string|nil (success, error message)

exports['lw-characters-api']:DeleteCharacter(stateId)
-- Hard delete. No tombstone. Pruning use only.
-- Returns boolean
```

## Events fired

| Event | Args | When |
|---|---|---|
| `lw-characters-api:characterCreated` | `license2, stateId` | Character row first written |
| `lw-characters-api:characterDeleted` | `stateId` | Hard delete executed |
| `lw-characters-api:characterStatusChanged` | `stateId, newStatus, oldStatus` | Status column updated |
| `lw-characters-api:pruningRequired` | `source, over` | Player over slot allowance on connect |
